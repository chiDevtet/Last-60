# Brand

## Name

**Asteroid Protocol** (formerly **LAST60**). The product and its mechanic are unchanged: every five
minutes, eligible creator fees are allocated to payouts for the last unique buyers and randomly drawn holders, at a moment inside
the final 60 seconds. The tagline stays **"The final minute pays."**

The rebrand covers everything people see: the website, metadata, social images, wallet signing prompts,
the live engine terminal, reports and documentation. Internal identifiers keep the `last60` namespace so
existing deployments, databases and on-chain records stay valid:

| Kept as-is | Why |
|---|---|
| `LAST60_*` environment variables | existing `.env` files and process managers keep working |
| `last60:v1:<claim>` / `last60:custody:v1:<id>` funding memos, `last60:r<round>:<payoutId>` payout memos | on-chain correlation: transfers already sent (or being sent) with these memos must still match |
| `last60` database name, stream ids (`bonding_curve_last60_reward_contribution`, `forge_platform_lp_last60_contribution`, `last60_funding_inflow`, route `last60_destination`), fields such as `expectedLast60` | stored records and their indexes |
| `last60/wallet-export/v1`, `last60/wallet-import/v1` HKDF labels | key-derivation domain separation (never shown to anyone) |
| `@last60/*` workspace packages, `last60-*` PM2 process names | internal; renaming churns every import and every operator runbook |

The production domain in [Deployment](DEPLOYMENT.md) (`last60.fun`) is unchanged until a new one is
chosen; set `PUBLIC_SITE_URL`, `CORS_ORIGINS` and `NEXT_PUBLIC_SITE_URL` when it moves. `NEXT_PUBLIC_APP_NAME`
defaults to `Asteroid Protocol` (site title, admin sign-in statement).

## Concept — "the orbit"

A blade-cut metal **A**, the apex with no crossbar, circled by a burning **orbit** that threads through
the gap cut in its right leg and ends in a **flare**. On the website the flare is the moment a round
closes: the countdown's elapsed minutes fill in the mark's silver, and the final arc, the last 60
seconds, ignites in the orbit's colours (Ember → Flare).

## Assets (`brand/`, generated by `bun run brand:render`)

The master artwork is kept exactly as supplied in `brand/source/`: `asteroid-mark.webp` (the rendered
mark, 1254 × 1254) and `asteroid-banner.webp` (2000 × 667). Large raster assets are cut from it. Everything
that must stay sharp at small sizes uses a **vector redraw** of the mark, traced in the artwork's own
coordinate space: the orbit is an ellipse fitted to the artwork with a tapered width profile.

## Wordmark

**ASTEROID** over **—— PROTOCOL ——**, as in the supplied banner. Outlined from **Michroma** (SIL Open
Font License 1.1, `@fontsource/michroma`, a dev dependency of the render script only) and emboldened
with a round-joined stroke, since Michroma has a single weight. The A of ASTEROID is drawn as **Λ**, the
mark's apex. PROTOCOL is tracked out to 65 % of the word's width, with rules running to its edges.
The wordmark is vector paths, so it renders identically everywhere; Michroma is never shipped as a web
font or used for running text.

## Colour

| Token | CSS | Hex | Use |
|---|---|---|---|
| Void | `void` | `#07080C` | page background |
| Carbon | `carbon` | `#0D1017` | surfaces, chart surface |
| Graphite | `graphite` | `#141924` | raised surfaces |
| Frost | `frost` | `#E9EDF5` | primary text; the mark's silver; elapsed countdown minutes |
| Mist | `mist` | `#8B93A7` | secondary text |
| Flare | `signal` | `#FFB547` | brand accent, live states, countdown, focus ring |
| Ember | `pulse` | `#FF7A1A` | the final arc, final-minute intensity |
| Series | `series` | `#1A9FCC` | chart marks; kept from the previous identity because it passes the chart-colour validator on the dark surface (lightness band, chroma, contrast) |
| Good / Warn / Bad | `good` / `warn` / `bad` | `#25A06C` / `#BF8A16` / `#E0565A` | status only, always with an icon + label (✓ ◷ ✕); red/amber CVD separation is in the 6–8 band, so colour is never the only cue |

Flare and Ember are the orbit. **Warn sits near them in hue**, so it always ships with its ◷ icon and a
label, and Flare never marks a status. The CSS token names (`signal`, `pulse`) are unchanged from the
previous identity; only their values moved.

Light-background lockups use a graphite mark (`#59606B` → `#0D1016`), `#0A0D14` text and a deeper
orbit (`#C9560A` → `#EE9A1A`) without the bloom.

## Typography

* **Michroma** — the wordmark only (outlined).
* **Geist** — UI, headings, figures (semibold for values; proportional figures for standalone
  numbers).
* **Geist Mono** — terminal, addresses, signatures, labels; tabular figures for columns and the
  ticking clock (so digits don't jitter).

## Voice

Fintech-precise, not casino. Say *recipients*, *rewards*, *eligible fees*, *settled*. Avoid
*win*, *jackpot*, *lucky*, *bet*. Every claim on the site is something the chain can verify.

Brand guidelines are also published at `/brand` on the website.
